# ePlanet Speakers Academy Website

Official website for **ePlanet Speakers Academy**, an English Speaking & Communication Skills Academy located in **Ismailpura, Kamptee, Maharashtra**.

> **“No Copy-Pen Learning. Understand the Concept. Speak English Directly.”**

---

## 🌟 Academy Overview

At **ePlanet Speakers Academy**, we believe English becomes easy when you understand the concept. Our teaching method focuses on practical learning instead of making students simply copy notes and memorize rules. We help students understand English in an easy way and start speaking it directly in real-life situations.

### Core Highlights:
- **No Copy-Pen Method**: Learn through understanding and practical speaking exercises.
- **Easy Concept Learning**: Complex English concepts explained in clear, everyday terms.
- **Direct Speaking Practice**: Speak directly in English without translating in your head.
- **Overcoming Hesitation**: Supportive and friendly environment for all learners.
- **Single Main Program**: Practical English Speaking Classes for students, job seekers, and adults.

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/tubazainab/E-Planet-Academy.git
   ```
2. Navigate to the project directory:
   ```bash
   cd E-Planet-Academy
   ```
3. Open `index.html` directly in any web browser, or launch a local server:
   ```bash
   python -m http.server 8000
   ```
4. Open `http://localhost:8000` in your browser.
